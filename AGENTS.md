# AGENTS.md

## Project

- `oxdg` is a modern CLI tool for analyzing JavaScript and TypeScript module dependencies, inspired by madge.
- The project is an ESM TypeScript package. Use Node.js 22 or newer for the published CLI and Bun 1.4.2 for development commands.
- Keep relative TypeScript imports explicit with their `.ts` extension, matching the existing `NodeNext` configuration.

## Repository layout

- `src/analyzer/`: source discovery, import extraction, and module resolution.
- `src/graph/`: graph data structures, queries, filtering, and cycle detection.
- `src/render/`: text, JSON, Mermaid, D2, and SVG renderers.
- `src/cli/`: command-line parsing and entrypoint.
- `src/index.ts`: public API exports.
- `test/`: Bun tests and temporary fixture-based integration coverage.

## Development

```bash
bun install
bun run check
bun run lint
bun run format:check
bun test
```

- Keep CLI structured output on stdout and diagnostics on stderr.
- Preserve stable module IDs and deterministic renderer output when changing analysis or rendering.
- Do not edit `dist/` or `node_modules/` by hand; `dist/` is generated by the build and ignored by Git.
- For packaging or release-related changes, also run `bun run build` and `bun run release:check`.
- Update tests when changing observable API or CLI behavior.
